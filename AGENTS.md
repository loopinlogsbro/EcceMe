# ecce.me

This is a Hugo site deployed by Cloudflare Pages from GitHub's `master` branch.

- Build with `./scripts/build-site` and preview locally with `./scripts/hugo server`. Both use the Hugo version and checksums in `hugo.lock`. Keep generated output out of commits.
- Make changes on a topic branch and open a PR against `master`. Logan merges the PR in GitHub when it is ready to publish.
- GitHub branches, PRs, and Pages previews are public. Get Logan's clearance before pushing new editorial copy. Keep working drafts, private context, and source writing samples outside the repository.
- Put new editorial content in Markdown. Keep project layout changes in this repository's layouts and assets. Project writeups use lowercase URLs at the site root.
